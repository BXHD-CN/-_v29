# 首页视觉 V4：复古气质 + 3D 交互

> 灵感来源：B 站《超酷网页设计灵感: 复古气质+3D交互》(BV1qUmMBBEoe)。视频本身无法内嵌观看，按标题与标签（网页/UI/交互/动态设计）提炼为：**纸感印刷 + 硬阴影 + 衬线大字 + 3D 旋转交互**。
> 实现方式：原生 JS + Canvas 2D，无第三方库（站点 CSP 为 script-src 'self'）。

## 1. 复古视觉系统

| 元素 | 做法 |
| --- | --- |
| 纸张底色 | #F4ECDD 米纸色 + SVG 噪点纸纹 + 网点半调（左上角淡出） |
| 主色 | 墨黑 #17130F、铁锈红 #C0522B、芥末黄 #D9A227、橄榄绿 #5C6B3F、灰蓝 #4B6784、梅紫 #6E4B63 |
| 字体 | 标题 Georgia / 宋体衬线；标签用 Courier New 等宽字体，全大写加字距 |
| 版式 | 粗黑边框（2px）、硬阴影（偏移无模糊）、印章旋转贴纸、编号章节、黄色跑马灯 |
| 卡片 | 纸卡 + 顶部色带 + 3px 硬阴影，悬停轻微位移 |

## 2. 3D 交互

1. **线框知识球**（右上墨色面板）：Canvas 2D 手写经纬线投影，缓慢自转，可拖拽旋转；红点标记 6 类资产，底部实时术语数。
2. **3D 能力卡片环**：6 张卡片按 60° 排布在半径 540px 的圆环上，透视 1500px；自动缓慢旋转，**拖拽旋转**、左右按钮/方向键切换、点击进入对应板块；卡片背面不显示，形成“转盘”感。
3. **知识库流动图**：伪 3D 轨道图，节点按椭圆轨道缓慢公转，连线为渐变、粒子沿线流动；悬停显示分类数量，点击跳转。
4. **微交互**：卡片/按钮硬阴影位移、跑马灯悬停暂停、章节入场揭示。

## 3. 降级与性能

- `prefers-reduced-motion` 或移动端（≤767px）：卡片环改为单列网格、球体与知识图只画一帧、跑马灯停止；
- 页面隐藏时暂停所有 rAF；窗口 resize 时重算画布并重绘（修复过 canvas 被清空的问题）；
- Canvas 用 devicePixelRatio 上限 2，节点数控制在 6+24 以内。

## 5. 可调参数

- 卡片环：`ring.radius`（默认 540）、`autoRotate` 中 `-0.12` 为转速；
- 线框球：`orbLoop` 中 `orb.ry += 0.004` 自转速度；
- 知识图：`layoutNodes` 中 `t * 0.18` 公转速度；
- 配色：home-v4.css 顶部 CSS 变量。
